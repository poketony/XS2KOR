# Disc 2 자막

**`movie/kr/*.txt`를 UTF-8로 번역하고 `2.ApplySubtitles.bat`를 실행하면
외부 Xenosaga2의 `xenosaga2_UNPACKED/movie`에 자동 적용합니다.**

25개가 대상입니다. `movie/jp`는 일본어 참고본입니다. 기존 번역을 모두 보존해 kr로 옮겼습니다.
`1.PrepareSubtitles.bat`는 없는 편집 파일만 준비하며 기존 kr는 덮어쓰지 않습니다.
적용 성공 후 외부 폴더의 Disc 2 ROM 빌더를 실행하세요.
상세 사용법과 오류 처리는 [공통 설명](../tools/subtitles/README.md)을 참고하세요.
