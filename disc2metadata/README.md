# Disc 2 실행 파일 텍스트 번역

**이 폴더의 `SLPS_strings.txt`에서 두 번째 `|` 뒤를 번역하고
`2.Rebuild.bat`를 실행하면 기존 자간·버튼·메뉴 통합 패치를 포함한
`SLPS_253.69.new`와 `MainMenu.txd.new`가 만들어집니다.**
OV02 항목을 수정하면 `OV02.OVL.new`도 함께 나옵니다. 기존 OV02 결과가 있으면 번역 원복 시에도 갱신합니다. 함께 나온 파일은 함께 적용하세요.
TXT는 원본에서 추출했으며, 요청한 아이템 문구 4개는 번역해 두었습니다.
ELF·OV02는 디스크 루트, 메뉴 TXD는 아카이브의 `yosikawa/MainMenu.txd`에 적용합니다.

- ELF 원본은 `../disc1metadata/slps_253.68.original`입니다. Disc 1·2 원본 내용이 동일하므로 전용 기준본 한 파일을 공유하며, OV02는 이 폴더의 `OV02.OVL`을 사용합니다. **전용 원본을 출력 파일로 덮어쓰지 마세요.** 해시가 다르면 중단합니다.
- 적용용 폴더와 자동 연동하지 않습니다. 결과를 사용자가 직접 옮기며, 그쪽의 실행 파일을 교체해도 번역 툴의 원본에는 영향이 없습니다.
- 도구는 `../disc1metadata/elf_text_tool.py`를 공유합니다. BAT는 어느 위치에서 실행해도 됩니다.
- Python 3.10 이상이 필요합니다. 한글은 프로젝트의 기존 한글-한자 대응표로 자동 변환합니다.
- TXT의 주소·바이트 수, 제어코드와 `%d` 등은 그대로 두고 UTF-8로 저장하세요.
- 아이템 개수는 반각 `00`을 하나 유지하면 앞부분 길이에 맞춰 기록 위치도 수정됩니다.
  `00578D98|6/10|을/를 00개`를 사용할 수 있습니다.
- `00579670`의 `을/를 `과 `00579678`의 `개 ` 끝에는 반각 공백을 하나씩 유지하세요.
  `{20}`으로 명시해도 같은 공백 한 바이트로 저장됩니다.
- 영상 스킵·PAUSE 안내(`001945E0`, `00194610`)의 초과는 인접 공간, 검토한 ELF 여백 순으로 자동 재배치합니다. 다른 항목의 초과나 공간 부족은 중단합니다. 상세 한계는 공통 사용법을 보세요.
- 기존 `.new`는 검증 후 자동 갱신합니다. 같은 내용이면 `[UNCHANGED]`로 넘어가므로 BAT를 반복 실행해도 됩니다. 원본과 기존 번역 TXT는 덮어쓰지 않습니다.
- 출력은 파일별로 `.pending`에 완전히 기록·검사한 뒤 교체합니다. 실패한 실행의 결과는 적용하지 말고 오류 해결 후 다시 리빌드하세요. 정상 완료하면 임시 파일은 남지 않습니다.
- TXT 무수정이어도 실행 코드 패치를 적용한 결과를 만듭니다. `1.Export.bat`는 TXT 최초 생성용이며 기존 번역을 덮어쓰지 않습니다.
- **기존 자간·아이콘 공백 복구·특전창 정렬·슬롯 표기 수정이 모두 포함됩니다.**
  두 원본 ELF와 패치 대상 바이트가 같음을 확인했습니다. 게임에서의 Disc 2 실행 확인은 별도입니다.
- 메뉴는 공통 `../0.xenosaga0/yosikawa/MainMenu.txd.txt`에서 함께 리빌드합니다.
  기존 정상 통합본의 메뉴 TXD를 이미 적용했다면 이번 ELF만 교체해도 됩니다.
- Disc 1/2 원본 ELF 내용이 같지만, 두 TXT의 편집은 자동 공유되지 않습니다. 같은 번역을 쓸 때는 양쪽 TXT에 반영하세요.

편집 예시, `\n`과 `\\n` 구분, `00` 개수 자리 및 포함 범위는
[공통 사용법](../disc1metadata/README.md)을 보세요.

저장 없이 검사만 하려면 `python -B ../disc1metadata/elf_text_tool.py verify --disc 2`를 실행합니다.
