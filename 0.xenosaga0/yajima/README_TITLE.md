# 타이틀 로고 편집

**`title_graphics/title_KOR.png`와 `title2_KOR.png`를 수정하고 `4.RebuildTitle.bat`을 누르면 됩니다.**
결과는 `title_rebuilt/title.bin`, `title2.bin`입니다. 필요한 BIN을 게임 작업 폴더의 `yajima`에 직접 옮겨 리팩하세요. 이 도구는 원본·현재 적용용 BIN·ISO를 덮어쓰거나 외부 폴더로 자동 복사하지 않습니다.

## 원본과 편집본

| 파일 | 용도 |
|---|---|
| `title.bin.original`, `title2.bin.original` | 자료 폴더에서 확인한 일본어 기준 원본. 해시를 검사하므로 교체하지 않습니다 |
| `title_graphics/title.png`, `title2.png` | 일본어 원본에서 추출한 기본 PNG |
| `title_graphics/title_KOR.png`, `title2_KOR.png` | 현재 `yajima/title.bin`, `title2.bin`의 한글 그림을 재현하는 편집본. 이 두 PNG를 수정합니다 |
| `title_rebuilt` | 별도 BIN 결과와 작은 검증 기록 `build.json` |

`_KOR.png`가 있으면 우선 적용하고, 없으면 같은 이름의 기본 PNG를 읽습니다. `_KOR`를 치우고 기본 PNG를 일본어로 유지하면 일본어 원본 상태로 되돌릴 수 있습니다. 기본 PNG를 직접 편집하는 방식도 지원하지만 원본과 편집본을 나누는 `_KOR` 방식을 권장합니다.

## 이미지 주의 사항

- **512×448, 채널당 8비트 RGBA PNG**를 유지하세요. 투명 배경·알파·캔버스 크기를 유지하고 RGB, JPEG, 불투명 미리보기로 바꾸지 마세요. 잘못된 크기는 자동 리사이즈하지 않고 중단합니다.
- 팔레트 이미지가 아닙니다. RGB는 그대로 저장하고 알파만 PS2의 0~128단계에 맞춰 반올림합니다. 따라서 PNG와 재추출 PNG의 알파가 최대 1단계 다를 수 있습니다.
- `title`과 `title2`의 디스크 표기 차이를 유지하세요. 한쪽 PNG를 다른 쪽에 그대로 복사하지 않습니다. 두 파일은 각각의 원본으로 리빌드합니다.
- PSD는 자유롭게 보관할 수 있지만 리빌더는 PNG만 읽습니다. 다른 이름의 PNG가 편집 폴더에 있으면 오적용 방지를 위해 중단합니다.

## 재추출과 재실행

`3.ExtractTitle.bat`은 없는 기본 PNG만 일본어 원본에서 추가하고, 기존 PNG·KOR·PSD는 건드리지 않습니다.

리빌드는 두 PNG의 형식·원본 해시·ARX 재해독 결과를 모두 검증한 뒤 저장합니다. 이전 도구 결과는 갱신하지만 결과 BIN을 사람이 별도로 수정한 경우 덮어쓰지 않습니다. `.pending`이 있거나 실패 메시지가 나오면 해당 실행의 결과는 사용하지 마세요. 저장 도중 실패하면 일부 결과만 갱신됐을 수 있습니다.

무편집 상태에서는 일본어 원본 BIN을 그대로 유지하고 불필요한 결과를 만들지 않습니다. 이미 생성한 결과가 있으면 번역을 취소한 경우에도 최신 원본 상태로 갱신합니다. ARX 재압축으로 파일 크기가 달라질 수 있으므로 게임 적용 시 아카이브도 정상 리팩해야 합니다.

검증만 할 때는 이 폴더에서 `python -B title_tool.py verify`를 실행합니다. `titlebg2.bin`, `titleobj.xtx`, synopsis와 기존 `1.Export.bat`·`2.Rebuild.bat`은 별도이며 이번 도구가 처리하지 않습니다.

Python 3.10 이상과 Pillow가 필요합니다. 자료 폴더나 `codex-lab` 없이 이 작업 폴더의 원본·PNG·도구만으로 실행됩니다. 실제 게임 화면 확인은 별도로 필요합니다.
