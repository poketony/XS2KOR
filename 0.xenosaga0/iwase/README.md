# 시민과 퀘스트 및 보물 설명 번역

**이 폴더의 `Citizen.txt`·`QuestMes.txt`·`Treasure.txt`에서 따옴표 안의 문장을 번역하고, `2.Rebuild.bat`를 더블클릭하면 됩니다. 변경한 파일만 `rebuilt`에 게임용 TXT로 만들어집니다.**

예: `Citizen.txt` 수정 → `2.Rebuild.bat` 실행 → `rebuilt/Citizen.txt`를 게임의 같은 위치에 적용.

## 편집 대상

| 편집 파일 | 내용 | 번역 항목 |
| --- | --- | ---: |
| `Citizen.txt` | 시민 프로필 | 250 |
| `QuestMes.txt` | 퀘스트 설명과 진행 문구 | 288 |
| `Treasure.txt` | 보물 설명 | 54 |

원본과 같은 `No.`, `Name:`, `Profile:` 등의 배치입니다. 따옴표 안만 수정하고 **UTF-8로 저장**합니다. `No.` 번호·항목명·따옴표·중괄호는 유지합니다. 게임 내 줄바꿈은 원본처럼 `\n`을 씁니다. 편집기의 실제 줄바꿈과 그 뒤 들여쓰기는 문서 배치용이며 게임 줄바꿈이 아닙니다.

**일반 반각 공백으로 번역해도 됩니다. 리빌드가 문장 속 반각 공백을 전각 공백으로 자동 변환합니다.** 게임 로더가 반각 공백을 삭제하기 때문입니다. 편집 TXT·기준 원본·실행 파일은 변경하지 않습니다. 전각 공백도 2바이트로 계산해 길이 초과를 막지만 실제 화면의 줄 배치는 게임에서 확인해야 합니다.

**게임에 넣는 것은 `rebuilt`의 TXT입니다. 편집용 UTF-8 TXT를 그대로 넣으면 안 됩니다.**

## 실행과 보관

- TXT 하나만 처리하려면 그 파일을 `2.Rebuild.bat`에 드롭합니다. 더블클릭하면 세 파일을 먼저 검사한 뒤 변경분만 만듭니다.
- `original`: 기준 원본 TXT 3개. 수정하지 않습니다. manifest는 사용하지 않습니다.
- `rebuilt`: 변경된 게임용 TXT만 생성합니다. 무편집이면 아무 파일도 만들지 않습니다.
- `1.Export.bat`: 편집 TXT를 새로 만들 때만 사용합니다. 이미 준비되어 있으므로 평소에는 실행할 필요가 없습니다.

기존 번역과 결과는 덮어쓰지 않습니다. 이전 결과를 보관하고 다시 만들려면 이 폴더의 PowerShell에서 다른 결과 이름을 지정합니다.

```powershell
python -B field_text_tool.py rebuild Citizen.txt rebuilt/Citizen_v2.txt
```

## 제한

한글은 `../yosikawa/XENOSAGA KOR-JPN.json`의 글자 배치를 사용합니다. 적용하는 게임 폰트도 이 표와 맞아야 합니다. 검증한 기준 원본이나 글자 표가 바뀌면 중단합니다.

길이 제한은 게임 변환 후 바이트 수입니다. 한도를 넘으면 해당 항목과 길이를 표시합니다. 문장 안의 따옴표·탭·지원하지 않는 글자·`\n` 이외의 백슬래시 명령은 거절합니다. 반각 공백을 자동 변환하지 않고 발견 시 중단하려면 명령에 `--spaces reject`를 붙입니다.

`Citizen2.txt` 등 이름에 `2`가 붙은 파일은 동일한 실행 경로가 확인되지 않아 제외했습니다. 원본 자동 적용이나 ISO 제작은 하지 않습니다. Python 3.10 이상이 필요합니다.

592개 필드 무편집 왕복, 2,350개 한글 매핑, 원본 배치의 여러 줄 편집, 공백 자동 변환, 길이·구조·원본 변경 차단을 검사했습니다. 상세 기록은 `codex-lab/asset-pipeline`에 있습니다.
