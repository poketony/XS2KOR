# Simajiri ESD ESP 파이프라인

실사용 도구는 이 폴더의 `esd_esp_tool.py`이다. `codex-lab`의 코드나 자료 없이 실행할 수 있다. Python, NumPy, Pillow가 필요하다.

## 핵심 사용법

**폴더를 드롭하기 번거로우면 `2.Rebuild.bat`을 더블클릭하고 `ce001_999`처럼 폴더 이름만 입력한 뒤 Enter를 누르면 된다.**
`graphics_extract/esd`·`graphics_extract/esp`에서 찾는다. 같은 이름이 양쪽에 있으면 `esd/ce001_999`처럼 구분한다. 빈 입력은 취소하며, 기존 폴더·manifest 드롭 방식도 그대로 쓸 수 있다.

**2026-10-29 스크린샷의 `旧ミルチア市街`는 `graphics_extract/esd/ce001_999/images/000029c0_m01-a.alpha.png`이다.**
이 PNG를 수정해서 같은 폴더에 **`000029c0_m01-a.alpha_KOR.png`**로 저장하고,
**`graphics_extract/esd/ce001_999` 폴더를 `2.Rebuild.bat`에 드롭하면 된다.**
결과의 `esd/ce001_999.esd` 및 함께 생성된 ESP는 `build-report.json`의 상대경로대로 직접 적용한다.
지명과 색/발광 연출은 별도이므로 글자 마스크만 편집한다. 기존 파이프라인으로 이미 지원하는 자산이며 중복 도구는 필요 없다.

**`graphics_extract/esd/파일명/images/` 또는 `graphics_extract/esp/파일명/images/`의 PNG를 포토샵으로 수정하고, 같은 폴더에 `원래이름_KOR.png`로 저장한 뒤 `파일명` 폴더를 `2.Rebuild.bat`에 드롭하면 된다.** 결과는 `graphics_rebuilt/`에 생긴다. 원본 팔레트로 색상·투명도를 자동 양자화하므로 직접 인덱스 색상으로 변환할 필요는 없다.

예: `ce001_999/images/000029c0_m01-a.alpha.png`를 편집해 그 옆에 **`000029c0_m01-a.alpha_KOR.png`**로 저장하고, **`ce001_999` 폴더**를 드롭한다. `images` 폴더를 드롭하는 것이 아니다.

PNG는 원래 가로·세로 크기를 유지하고 포토샵의 8비트/채널로 저장한다. 지명 마스크는 **검정 배경 + 흰 글자**를 유지하거나 **투명 배경 + 글자**로 만들면 된다. 전자는 밝기, 후자는 알파 채널을 읽는다. 지명 색 자체는 원래 게임의 별도 색상 텍스처를 따른다.

## 작업 순서

```text
simajiri/
  original/
    esd/                       # 원본 ESD 사본
    esp/                       # 원본 ESP 사본
  graphics_extract/
    catalog.json               # 선별한 글자 그래픽의 추출 경로
    esd/<파일명>/images/       # 편집할 글자 PNG만
    esp/<파일명>/images/
  graphics_rebuilt/             # 리빌드 작업별 결과
  esd_esp_tool.py
  text_graphics.json            # 원본 해시 + 검증된 이미지 키 목록
  1.Export.bat
  2.Rebuild.bat
```

원본 사본과 **선별한 글자 그래픽 34개 파일 / PNG 84개**를 배치했다. 외부 `Xenosaga2` 디렉터리는 읽기만 했으며, 추출 폴더마다 원본 바이너리를 중복 복사하지 않는다. 원본 1,124개는 동일 내장 리소스 동기화를 위해 유지한다. 배경·장식·파편 등 추출하지 않은 이미지는 원본 안에 그대로 남는다.

1. `graphics_extract/esd/<파일명>/images/` 또는 `graphics_extract/esp/<파일명>/images/`의 PNG를 편집하고, 같은 위치에 파일 확장자 직전 `_KOR`를 붙여 저장한다. 원본 PNG는 그대로 둔다.
2. 해당 `<파일명>` 폴더나 그 안의 `manifest.json`을 `2.Rebuild.bat`에 드롭한다.
3. `graphics_rebuilt/<파일명>_esd/` 또는 `<파일명>_esp/`의 변경 파일과 `build-report.json`을 확인한다. 결과 안의 `esd/`, `esp/`는 원본 상대경로이다. 원본에 자동 적용하지 않는다.

`1.Export.bat`를 더블클릭하면 선별 목록 전체를 추출한다. 대상 `.esd` 또는 `.esp`를 드롭하면 그 파일의 글자 이미지만 추출한다. 목록에 없는 파일은 기본 추출을 거절한다. 이미 배치된 추출 폴더는 편집물 보호를 위해 덮어쓰지 않는다. 결과 폴더도 마찬가지이므로 재리빌드는 아래처럼 새로운 출력 폴더를 지정한다.

지명 글자는 `-a.alpha.png`로 끝나는 **그레이스케일 투명도 마스크**이다. 흰색은 불투명, 검정은 투명이다. 수정본은 그레이스케일, RGB, RGBA PNG를 사용할 수 있다. 실제 투명 픽셀이 있으면 알파 채널을, 전부 불투명하면 밝기를 마스크로 사용한다. 일반 이미지는 RGB와 알파를 함께 원본 팔레트에 맞춰 양자화한다. 팔레트, 스크립트, 패딩, 파일 크기는 보존한다.

`_KOR.png`가 있으면 그 파일을 우선 사용한다. 없으면 기존 PNG를 읽으므로 이전 직접 편집 방식도 동작한다. `_KOR`를 쓸 때 원본 PNG와 원본 게임 파일은 변경하지 않는다. 잘못된 `_KOR` 파일명이나 크기는 저장 전에 오류로 알린다. `build-report.json`의 이미지별 `input_png`, `conversion`, `max_channel_error`에서 사용한 수정본·마스크 해석·양자화 오차를 확인할 수 있다. 원본 팔레트에 없는 색은 가장 가까운 색으로 바뀐다.

수정하지 않은 픽셀 인덱스는 유지한다. 선별 manifest는 글자 PNG만 요구하며 다른 이미지가 없어도 리빌드할 수 있다. 선택하지 않은 이미지와 팔레트가 불명확한 이미지는 원본 그대로 보존한다. 원본 해시나 편집 PNG 크기가 바뀌면 리빌드를 중단한다. `manifest.json`과 `text_graphics.json`은 편집하지 않는다.

## 명령행

아래 명령은 이 `simajiri` 폴더를 현재 디렉터리로 두고 실행한다.

```powershell
python -B esd_esp_tool.py rebuild graphics_extract/esd/ce001_999
python -B esd_esp_tool.py rebuild graphics_extract/esd/ce001_999 graphics_rebuilt/ce001_999_v2
python -B esd_esp_tool.py audit
```

다시 추출하려면 별도 작업 폴더를 명시한다.

```powershell
python -B esd_esp_tool.py export original/esd/ce001_999.esd graphics_extract/esd/ce001_999_fresh
```

빈 추출 공간에 선별본 전체를 배치하는 명령은 `python -B esd_esp_tool.py export-text`이다. 분석 등으로 특정 컨테이너의 모든 이미지가 정말 필요할 때만 `export`에 `--all-images`를 명시한다. 이전 전체 추출 manifest의 리빌드 호환성은 유지한다.

`original` 아래의 원본으로 추출한 작업은 리빌드 시 그 디렉터리를 자동 검색한다. 파일 전체가 원본 ESD와 동일한 외부·내장 사본만 함께 수정해 **결과 폴더로** 출력한다. 이름만 같고 내용이 다른 ESD는 동기화하지 않는다. 외부 원본을 직접 사용한 작업은 기본적으로 해당 파일만 처리하며, 필요할 때 `--sync-root`를 명시한다.

출력 경로를 생략하면 현재 작업 디렉터리와 관계없이 도구 옆의 `graphics_extract/`, `graphics_rebuilt/`를 사용한다. 명시하는 출력도 이 `simajiri` 내부여야 하고 `original`에는 쓸 수 없다. 무편집 리빌드는 게임 파일을 복제하지 않고 보고서만 만든다. 여러 작업의 결과에 같은 ESP가 있으면 각각 원본 기준으로 만든 파일이므로 무작정 덮어 합치지 않는다.

2026-10-04 검증: 원본 1,124개의 SHA-256이 외부 원본 및 기존 조사 기록과 일치했다. 선별 PNG 84개를 다시 읽은 무편집 리빌드는 모두 원본과 바이트 단위로 같았다. 84개 각각의 1픽셀 변경 검사에서도 해당 픽셀 바이트 외에는 보존됐다. `_KOR` 우선 적용·양자화, RGB/투명 PNG 마스크 왕복, 잘못된 파일명·크기 거절을 포함해 전체 테스트 63개 통과. 최초 선별 추출물은 manifest·목록 포함 215,939바이트이다.
