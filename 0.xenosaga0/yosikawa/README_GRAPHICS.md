# 메뉴 글자 그래픽

**`graphics`의 PNG를 포토샵에서 수정해 옆에 `원래이름_KOR.png`로 저장하고, `2.RebuildGraphics.bat`를 실행하면 됩니다.**
예: `obj_item.png` → `obj_item_KOR.png`. 결과는 `graphics_rebuilt`의 XTX이며, 성공 메시지를 확인한 뒤 필요한 파일만 직접 게임 작업 폴더의 같은 위치로 옮기세요.

- 편집용 PNG는 이미 추출되어 있습니다. 다시 필요하면 `1.ExtractGraphics.bat`를 실행하세요. 기존 PNG·`_KOR.png`·PSD는 덮어쓰지 않습니다.
- **검정 배경 + 흰 글자의 불투명 회색조 마스크**입니다. 지울 곳은 검정으로 채우세요. PNG의 크기는 유지하고, 색상·투명 배경은 넣지 마세요. 회색 안티앨리어싱은 원래의 16단계로 자동 양자화합니다. 8비트 회색조 PNG 또는 회색으로만 그린 RGB/RGBA PNG를 사용하세요.
- PNG 한 장은 기존 글자 영역입니다. 그 안에 새 문구가 들어가야 합니다. 영역 확대, UI 좌표·UV 변경, 런타임 정렬은 하지 않습니다.
- 원본 PNG를 바로 수정해도 됩니다. 같은 이름의 `_KOR.png`가 있으면 그것이 우선입니다. PSD는 참고용이며 읽지 않습니다. 작업 폴더에 이름이 다른 PNG를 넣으면 오적용 방지를 위해 오류를 냅니다.

## 대상

| PNG 이름 | 원본 | 내용 |
| --- | --- | --- |
| `ctrl_*.png` 22장 | `ctrl01.xtx` | 버튼·방향키·스틱 이름, 메뉴 조작 설명, 스테이터스·스킬·파티 |
| `font_character_select.png` | `font.xtx` | 캐릭터 선택 |
| `obj_*.png` 16장 | `obj01.xtx` | 아이템·스킬 등 일본어 메뉴 라벨 |

`ctrl_button_KOR.png` 한 장은 같은 버튼 문구 4곳에 함께 적용됩니다. 이외의 영어 라벨·아이콘·테두리는 추출/변경하지 않습니다. 이 마스크의 밝기는 편집용 인덱스 표현이며 게임의 최종 색상·합성 미리보기가 아닙니다.

## 원본과 결과

- 이 폴더의 XTX 3개는 해시 검증하는 기준 원본입니다. 덮어쓰지 마세요. 도구는 XS2KOR 안의 파일만 읽고 외부 Xenosaga2와 자동 연결하지 않습니다.
- 새로 수정된 XTX만 결과로 생성합니다. 무편집 상태에서는 원본과 바이트 단위로 같으며 새 결과 파일을 만들지 않습니다.
- 결과 폴더의 파일은 생성물입니다. `build.json`은 자동 검증 기록이므로 편집할 필요가 없습니다. 지난 생성 결과는 다음 빌드에서 갱신되지만, 사람이 따로 변경한 결과는 덮어쓰지 않고 중단합니다.
- 번역을 취소하려면 `_KOR.png`를 치우고 기본 PNG도 원본 그림으로 돌리세요. 다음 성공한 빌드는 이미 있던 해당 결과를 원본 상태로 갱신하여 이전 번역이 남지 않게 합니다.
- 실패 메시지가 나오면 그 실행의 결과는 적용하지 마세요. `.pending`은 중단된 임시 저장물입니다. 정상 성공 시 남지 않습니다.

필요 환경: Python 3.10 이상, Pillow, NumPy (`python -m pip install pillow numpy`). 공용 엔진은 `0.xenosaga0/texture_graphics.py`, GS 주소 표는 기존 `xtx 개발소/xtx_psmt4_codec.py`를 사용합니다. 독립 해독·무편집 왕복·다른 영역 보존 검사는 통과했지만 실제 게임 화면/UV 확인은 별도입니다.
