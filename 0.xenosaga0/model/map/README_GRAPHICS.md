# 맵 간판 그래픽

**`graphics`의 PNG를 포토샵에서 수정해 옆에 `원래이름_KOR.png`로 저장하고, `2.RebuildGraphics.bat`를 실행하면 됩니다.**
결과는 `graphics_rebuilt`의 TXY입니다. 성공 메시지를 확인한 뒤 직접 게임 작업 폴더의 `model/map`에 옮기세요.

| 편집 PNG | 내용 | 함께 바뀌는 파일 |
| --- | --- | --- |
| `uzu06_kanban.png` | 고서 간판 `古書`, 64×64 | `CFEVE15.txy`, `E2_UZU01.txy`, `E2_UZU06.txy` |
| `kanban01_new.png` | 간판 `海の男`, 192×128 | `E2_KUK11.txy` |

- 예: `uzu06_kanban_KOR.png` 한 장을 만들면 같은 간판 사본 3개에 함께 반영합니다.
- PNG 크기와 알파를 유지하세요. **각 원본 팔레트의 가장 가까운 RGBA 색으로 자동 양자화**합니다. 새 팔레트는 만들지 않습니다. 원본에 없는 색은 근사색이 됩니다. 변경하지 않은 픽셀은 기존 인덱스까지 보존합니다.
- `kanban01_new`는 반투명 간판입니다. 알파가 포함된 RGBA PNG로 저장하세요. 알파를 잃은 RGB PNG는 중단합니다. 불투명한 `uzu06_kanban`은 RGB PNG도 받습니다. 채널당 8비트 PNG를 권장합니다.
- 전체 맵이 아닌 간판 2종만 편집합니다. 다른 텍스처·팔레트·재질표·파일 크기는 유지합니다. 텍스처의 방향/UV는 바꾸지 않으므로 기존 그림 배치를 따라 편집하세요.
- 편집 PNG는 이미 추출되어 있습니다. `1.ExtractGraphics.bat`는 없는 기본 PNG만 추가하며 기존 PNG·`_KOR.png`·PSD는 덮어쓰지 않습니다.
- 기본 PNG를 직접 수정해도 됩니다. `_KOR.png`가 있으면 우선 적용합니다. 이름이 다른 PNG는 오류를 내므로 별도 보관하세요. PSD는 읽지 않습니다.

## 원본과 결과

이 폴더의 TXY 4개는 사용자 승인으로 한 번 복사해 해시 검증한 기준 원본입니다. 덮어쓰지 마세요. 이후 도구는 **XS2KOR 내부 파일만** 사용하며 외부 Xenosaga2에서 탐색·복사·동기화하지 않습니다.

새로 수정된 파일만 결과로 생성합니다. 무편집 빌드는 바이트 단위로 원본과 같으며 새 결과를 만들지 않습니다. `graphics_rebuilt/build.json`은 자동 검증 기록입니다. 지난 도구 산출물은 갱신하지만 사람이 별도로 수정한 결과는 덮어쓰지 않고 중단합니다. 번역을 취소하고 PNG를 원본으로 돌리면 이미 생성됐던 해당 결과도 원본 상태로 갱신합니다.

실패한 실행의 결과는 적용하지 마세요. 정상 성공 시 `.pending` 임시 파일은 남지 않습니다. Python 3.10 이상, Pillow, NumPy가 필요합니다 (`python -m pip install pillow numpy`). 공용 엔진은 `0.xenosaga0/texture_graphics.py`입니다.

이 파이프라인은 **일본어가 확인된 간판만** 다룹니다. 저해상도 네온 간판, 책장 `甲/丙/戊` 표식, 사용 여부가 미확정인 로고는 포함하지 않았습니다. 전체 맵 그래픽 검수 완료를 뜻하지 않으며 게임에서의 실제 노출/UV 확인은 별도입니다.
